# java-lotto-precourse
로또 (Lotto)

-구현할 기능 목록

1. 구입 금액 입력
- [ ] 콘솔로 구입 금액을 입력받는다.
- [ ] 금액이 1000원 단위가 아니거나 0 이하일 경우 [ERROR] 출력 후 재입력 받는다.

2. 로또 발행
- [ ] 1000원당 1장의 로또를 자동 발행한다.
- [ ] 각 로또는 1~45 사이의 중복 없는 6개의 숫자를 가진다.
- [ ] 발행된 로또 번호는 오름차순으로 정렬한다.
- [ ] 발행된 로또 번호를 출력한다.

3. 당첨 번호 및 보너스 번호 입력
- [ ] 당첨 번호 6개를 쉼표(,)로 구분하여 입력받는다.
- [ ] 보너스 번호 1개를 추가로 입력받는다.
- [ ] 1~45 사이의 숫자가 아니면 [ERROR] 출력 후 재입력 받는다.
- [ ] 당첨 번호와 보너스 번호가 중복되면 [ERROR] 출력 후 재입력 받는다.

4. 당첨 결과 계산
- [ ] 구매한 로또 번호와 당첨 번호를 비교해 일치 개수를 계산한다.
- [ ] 보너스 번호 일치 여부를 판단한다.
- [ ] 1~5등의 Rank를 구분한다.

5. 결과 출력
- [ ] 등수별 당첨 횟수를 출력한다.
- [ ] 총 당첨 금액을 계산한다.
- [ ] 수익률을 계산하고 소수점 둘째 자리까지 반올림해 출력한다.

6. 예외 처리
- [ ] 모든 잘못된 입력은 IllegalArgumentException을 발생시킨다.
- [ ] 모든 에러 메시지는 [ERROR]로 시작한다.
- [ ] 예외 발생 시 해당 단계부터 입력을 다시 받는다.
